# Primary-source research

Consulted 2026-10-10. These references support specific review choices; they do not certify this generator. Links to mutable upstream pages should be rechecked on future reviews.

- [Three.js r128 WebGLRenderer source](https://raw.githubusercontent.com/mrdoob/three.js/r128/src/renderers/WebGLRenderer.js): confirms the pinned renderer exposes outputEncoding and throws on failed context creation. The application must handle initialization failure itself. Its existing r128 usage should not be evaluated solely against the newest API.
- [Three.js migration guide](https://github.com/mrdoob/three.js/wiki/Migration-Guide): documents outputEncoding→outputColorSpace and changed color-management defaults at r152, and removal of classic three.js/three.min.js builds at r161. A current-version URL substitution is not a compatible upgrade for this global-THREE script. A future migration needs module-loading, color/light regression checks, WebGL support review and visual comparison. No upgrade was performed.
- [MDN anchor download property](https://developer.mozilla.org/en-US/docs/Web/API/HTMLAnchorElement/download): specifying a filename does not establish that downloading occurs. This supports changing “Saved” to “Download requested”.
- [MDN number inputs](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input/number): min, max and step define validity constraints; the application still needs coherent parsing/normalization. Native step validity is not an integer normalization step in the supplied handler.
- [MDN object URL release](https://developer.mozilla.org/en-US/docs/Web/API/URL/revokeObjectURL_static): revocation releases an object URL. The source schedules this after five seconds; this is cleanup, not download-completion evidence.
- [WAI labelling controls](https://www.w3.org/WAI/tutorials/forms/labels/): explicit programmatic associations are the basis for the toggle/numeric accessible-name findings. Nearby visible text alone is insufficient.
- [WAI preliminary accessibility checks](https://www.w3.org/WAI/test-evaluate/preliminary/): informs the keyboard, focus, contrast and zoom checklist. A source inspection is only preliminary and cannot establish accessibility conformance.
- [Diátaxis](https://diataxis.fr/): informs the separation of practical user steps, parameter reference, architecture explanation and troubleshooting; avoids burying everyday use inside developer notes.
- [OpenAI Codex modernization cookbook](https://developers.openai.com/cookbook/examples/codex/code_modernization): supports an evidence-led, reviewable workflow with tests and maintained documentation. Here the smallest implementation is a local checker plus explicit agent handoff; it does not claim automatic LLM execution or require credentials.
- [Gridfinity Rebuilt upstream](https://github.com/kennetek/gridfinity-rebuilt-openscad) and [its dimensional definitions](https://raw.githubusercontent.com/kennetek/gridfinity-rebuilt-openscad/main/src/core/standard.scad): corroborate 42 mm grid pitch, 41.5 mm base top dimensions, 0.5 mm base gap and the 0.8/1.8/2.15 mm base profile. The upstream top radius is 3.75 mm; this generator uses 4 mm. The upstream lip profile totals 4.4 mm before additional support. These are comparison points from a maintained implementation, not universal tolerances. This generator's 7 mm height unit, custom snap beads/grooves, 0.35 mm seat, half-grid foot arrangement and default dimensions must be treated as implementation choices unless independently verified. The upstream evidence does not prove the supplied half-grid feet fit a specific baseplate.
- [W3C contrast minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html): normal text requires at least 4.5:1. The baseline light secondary text tokens calculate 4.21:1; this provides a measured target for the focused round-2 color change. This calculation does not cover every composited preview/background state.

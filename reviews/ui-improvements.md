# Prioritized interface improvements

Historical baseline report: these findings describe the supplied immutable source, not the corrected working copy. See [current disposition](resolution.md) and [numbered review rounds](rounds/round-3.md) for fixes, accepted scope and remaining risks.


Source-only UI review: browser automation was unavailable and in-app file navigation was blocked; no rendered contrast, touch, focus traversal or screen-reader pass is claimed. Evidence refers to [the supplied HTML](../source/baseline/gridfinity_generator_4.html). These are recommendations, not implemented UI changes.

| Priority | Evidence / change | User benefit | Effort | Acceptance |
| --- | --- | --- | --- | --- |
| P1 | Invalid geometry still exports (derive/build functions; C2/C3 in code review). Place a specific error beside the conflicting control and disable export until resolved. | Prevents wasting a print on impossible combinations. | Medium | Shallow-cradle and oversized-label cases explain the conflict and cannot export. |
| P1 | Delayed pair export reads changing state (2765–2772). Snapshot the pair and show the model/dimensions being requested. | Both files belong together. | Small | Switching mode during the delay cannot alter the second file. |
| P2 | Empty toggle labels; number labels target slider siblings (262, 270–298, 532). Add explicit names, groups and units. | Keyboard/screen-reader users can identify every input. | Small | Accessibility tree exposes unique names and units for both slider and number input. |
| P2 | Alerts and toast lack live regions (194, 618, 2746). Add a concise polite status region, with errors linked via aria-describedby. | Changes are announced without reading the whole page. | Small | A committed invalid value and download request are announced once; dragging does not flood speech. |
| P2 | Shared P, first-entry changes and reset scope (2711–2740). Preserve configurations per mode, or clearly disclose shared settings. | Switching modes does not unexpectedly lose a desk-bin setup. | Medium | Bin→tray→bin has predictable documented values; resets identify their scope. |
| P2 | Controls show requested values while derivation trims them (1033, 1787); fractional count and rotated pack discrepancy. Show effective slot count, label width and notch dimensions next to inputs. | Users understand what will be exported. | Small–medium | Requested/effective differences have a reason and units; packet orientation and count agree throughout. |
| P2 | Initialization can fail before handlers bind (2193); “Saved” overstates anchor success (2750). Add loading/error state and honest “Download requested” status. | Recovery is possible and missing files are not mistaken for success. | Medium | CDN/WebGL failures produce actionable messages; download list confirmation remains separate. |
| P2 | Preview only supports pointer/touch camera controls (2255–2267). Add labelled rotate, zoom and reset-view buttons with keyboard support. | Preview can be explored without dragging. | Small | Keyboard-only user can inspect and reset every view with visible focus. |
| P2 | Fixed bar (167–178), 104 px body padding, 720 px max content width; small view buttons and safe-area padding. Validate 320/375 px screens, 200% zoom and large text. | Last controls and export actions stay reachable. | Small after measurement | No horizontal scroll, occluded focus or overlapping buttons; touch targets remain usable. |
| P3 | Most sliders have focus-visible styling; number fields remove outline (121), Firefox thumb focus is not custom-styled. Test focus and light/dark contrast before tuning. | Preserves simple style while making focus easy to follow. | Small | Measured text/control contrast and visible focus in supported browsers; no blanket accessibility-conformance claim. |
| P3 | Basic controls precede native advanced details (153+); warnings live near top summary, far from advanced settings. Keep model→configure→preview→export structure; group advanced options by affected part. | Users can locate the setting responsible for a warning. | Small | Each warning links to its control; body/lid, measurement/geometry and estimate-only settings are distinguished. |

Strengths worth retaining: labelled range inputs, native buttons and disclosure, pressed-state attributes, theme controls, explicit millimetre displays, model-specific visibility, large slider thumbs, reduced-motion CSS, and separate single-file download buttons. See [WAI source references](sources.md) for the basis of the naming and manual evaluation recommendations.
